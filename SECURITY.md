# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it by opening a private security advisory on GitHub or contacting the maintainers directly.

Please do not disclose security vulnerabilities publicly until they have been reviewed and addressed.
